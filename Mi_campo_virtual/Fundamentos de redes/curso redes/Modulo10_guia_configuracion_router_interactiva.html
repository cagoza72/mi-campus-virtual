10.1 Parámetros Iniciales del Router

Secuencia esencial para configurar un router Cisco en el modo de configuración global:

# Entrar a configuración global

Router# configure terminal

Router(config)# hostname R1

# Cifrar contraseña de acceso privilegiado

R1(config)# enable secret class

# Proteger consola y líneas VTY

R1(config)# line console 0

R1(config-line)# password cisco

R1(config-line)# login

10.2 Configuración y Verificación de Interfaces

Las interfaces de un router vienen **apagadas por defecto**. Debes asignarles IP y encenderlas explícitamente con `no shutdown`.

R1(config)# interface gigabitethernet 0/0/0

R1(config-if)# ip address 192.168.10.1 255.255.255.0

R1(config-if)# description Enlace hacia Switch LAN 1

R1(config-if)# no shutdown
